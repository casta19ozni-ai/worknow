# WORKNOW - REGLAS OBLIGATORIAS PARA AGENTES DE IA

## PROYECTO PRINCIPAL

- index.html es el archivo principal de WorkNow.
- NO reemplazar index.html completo.
- NO eliminar funcionalidades existentes.
- NO eliminar IDs existentes.
- NO renombrar funciones existentes sin autorización.
- Realizar cambios quirúrgicos sobre el código existente.

## GOOGLE MAPS

- NO eliminar la integración existente de Google Maps.
- NO reemplazar Google Maps por otro proveedor.
- NO modificar la inicialización del mapa sin autorización explícita.
- NO eliminar la lógica existente de geolocalización.
- NO modificar credenciales o referencias de Google Maps sin autorización.

## GOOGLE VERIFICATION

- NO eliminar ni modificar google90276d36355528d4.html.

## SUPABASE

- NO cambiar el proyecto Supabase existente.
- NO eliminar tablas, columnas o políticas RLS existentes.
- Conservar las funciones actuales antes de añadir nuevas.

## GIT

- NO modificar ni eliminar .git.
- NO ejecutar git init.
- NO ejecutar git reset --hard.
- NO ejecutar git clean -fd.
- NO eliminar archivos para limpiar el proyecto sin autorización.

## FORMA DE TRABAJO

Antes de modificar código:

1. Leer index.html completo.
2. Identificar IDs existentes.
3. Identificar funciones JavaScript existentes.
4. Identificar Google Maps.
5. Identificar Supabase.
6. Hacer cambios mínimos.
7. Conservar la estructura existente.
8. Informar qué archivos fueron modificados.

## REGLA PRINCIPAL

Si una modificación puede romper una funcionalidad existente,
detenerse y solicitar autorización antes de realizarla.
